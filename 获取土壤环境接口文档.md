# 设备名称与属性

当前仅有一个设备名称为：device

```
| 标识符 | 含义 | 数据类型 | 读写 |
|--------|------|----------|------|
| A | PH 值 | float | 只读 |
| B | 土壤湿度 | int32 (0-100%) | 只读 |
| C | 环境温度 | int32 | 只读 |
| D | 环境湿度 | int32 | 只读 |
| E | 光照 | int32 (lux) | 只读 |
| F | 水泵/继电器状态 | enum (0=关闭,1=开启) | **读写** |
| G | PH 报警状态 | enum (0=正常,1=报警) | 只读 |
| H | 土壤湿度报警状态 | enum (0=正常,1=异常) | 只读 |
| I | PH 阈值低 | string | **读写** |
| J | PH 阈值高 | string | **读写** |
| K | 土壤湿度阈值低 | string | **读写** |
| L | 土壤湿度阈值高 | string | **读写** |
| N | 氮含量 | string | **读写** |
| P | 磷含量 | string | **读写** |
| K1 | 钾含量 | string | **读写** |

```

后续增加氮磷钾也是这种格式

# 设备接口


## SSE 实时推送


**接口地址**:`/api/stream`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`text/event-stream`


**接口描述**:<p>Server-Sent Events 实时数据推送，每2秒检查数据变化，仅在数据有变化时推送</p>



**请求参数**:


| 参数名称    | 参数说明                   | 请求类型 | 是否必须 | 数据类型 | schema |
| ----------- | -------------------------- | -------- | -------- | -------- | ------ |
| device_name | 设备名，不传则推送所有设备 | query    | false    | string   |        |


**响应状态**:


| 状态码 | 说明 | schema     |
| ------ | ---- | ---------- |
| 200    | OK   | SseEmitter |


**响应参数**:


| 参数名称 | 参数说明 | 类型           | schema         |
| -------- | -------- | -------------- | -------------- |
| timeout  |          | integer(int64) | integer(int64) |


**响应示例**:

```javascript
{
	"timeout": 0
}
```

## 查询设备所有属性历史数据


**接口地址**:`/api/history/all`

**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`

| start       | 起始毫秒时间戳，默认24小时前 | query    | false    | integer(int64) |        |
| end         | 结束毫秒时间戳，默认当前时间 | query    | false    | integer(int64) |        |
| limit       | 每个属性最大返回条数(1-100)  | query    | false    | integer(int32) |        |

| 状态码 | 说明 | schema |
